# 00 – Installation

Willkommen im ersten Kapitel des Webentwicklungs-Tutorials.

Bevor wir mit HTML, JavaScript, Vue oder einem Backend starten können, richten wir zunächst unsere Entwicklungsumgebung ein.

In diesem Kapitel installieren und prüfen wir nur die Werkzeuge, die wir für die nächsten Schritte wirklich benötigen.

> **Wichtig:** Du musst noch nicht verstehen, wie alle Werkzeuge im Detail funktionieren.  
> Wir lernen sie im Laufe des Tutorials Schritt für Schritt kennen.

## Lernziele

Nach diesem Kapitel kannst du:

- Visual Studio Code starten und einen Projektordner öffnen,
- ein Terminal in Visual Studio Code öffnen,
- überprüfen, ob Node.js und npm installiert sind,
- überprüfen, ob Git installiert ist,
- ein einfaches JavaScript-Programm mit Node.js ausführen,
- die Developer Tools deines Browsers öffnen.

## Was installieren wir?

Für den Einstieg benötigen wir:

| Werkzeug | Wofür brauchen wir es? |
|---|---|
| Visual Studio Code | Code schreiben und Projekte bearbeiten |
| Node.js | JavaScript außerhalb des Browsers ausführen |
| npm | JavaScript-Pakete verwalten |
| Git | Änderungen an unserem Code verwalten |
| Browser | Webanwendungen anzeigen und untersuchen |

Weitere Werkzeuge wie PostgreSQL, Docker, Vue, Quasar und Express installieren beziehungsweise verwenden wir erst in späteren Kapiteln.

## Am Ende dieses Kapitels

Wenn alles funktioniert, kannst du im Terminal diese drei Befehle ausführen:

```bash
node --version
npm --version
git --version
```

Bei allen drei Befehlen sollte eine Versionsnummer angezeigt werden.

Außerdem wirst du dein erstes kleines JavaScript-Programm ausführen:

```js
console.log('Meine Entwicklungsumgebung funktioniert!')
```

Weiter geht es mit den [Voraussetzungen](./01-voraussetzungen.md).
